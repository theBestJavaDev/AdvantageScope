# Fonts

The Seattle Solvers website's typefaces, so SolversScope matches it:

- `orbitron-variable.woff2`: Orbitron (display / headings). SIL Open Font License 1.1.
- `inter-variable.woff2`: Inter (body text). SIL Open Font License 1.1.
- `azeret-mono-*.woff2`: Azeret Mono (labels, buttons, numbers). SIL Open Font License 1.1.

Latin subsets, as served by seattlesolvers.com. Used by `www/solvers-theme.css`.
